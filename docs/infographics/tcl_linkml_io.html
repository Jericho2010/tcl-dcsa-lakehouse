2. Build-Time Compiler
Zero Spark Cluster Deps

LinkML SchemaView Compiler

Runs locally or in CI via uv run python -m tcl_compiler.compile_dcsa. Walks every class, inherited slot, enum, regex, bound, and annotation deterministically.

  • Resolves imports across dcsa_common, tnt_v3, ebl_v3, jit_v1
  • Normalizes paths & escapes Spark SQL RLIKE backslashes (\\s)
  • Enforces zero drift in CI via git diff --exit-code

Why LinkML Is So Cool
Change a single physical limit (for example, tightening reefer temperature bounds or adding a new DCSA port-call phase) in one YAML line, run compile_dcsa.py, and your Python validator, JSON Schema, 5 ODCS data contracts, Databricks streaming quarantine predicates, and Unity Catalog documentation all update in lockstep — zero manual copy-paste, zero silent drift.
